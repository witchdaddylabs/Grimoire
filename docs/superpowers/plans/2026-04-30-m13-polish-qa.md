# M13 Polish + QA Implementation Plan

> _Historical milestone plan (completed). In this plan "Palace" is today's "Vault". The current roadmap is [README](../../../README.md)._

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stabilize the macOS-first MVP after the M4-M12 implementation pass, proving that local writing, persistence, import, retrieval, Ollama states, wards, export, and desktop shell behavior are reliable enough for continued product work.

**Architecture:** Keep the app macOS-first and local-first. Use React/Tauri/Rust/SQLite as already scaffolded, add only focused tests and small polish changes, and avoid new runtime services or mobile-first layout work. Cloud BYOK providers are intentionally deferred to M14; M13 should only audit the seams needed for that work and must not add cloud network calls.

**Tech Stack:** Tauri v2, Rust 1.95, rusqlite, React 19, TypeScript, Vite, Tailwind CSS v4, SQLite FTS5, local Ollama HTTP API.

```markdown
# AI Provider Readiness Audit

Date: 2026-04-30
Status: M13 audit for M14 cloud BYOK implementation

## Local-First Rule

Grimoire remains local-first. Ollama is the default local provider. Cloud providers require explicit user configuration, explicit provider selection, and an in-product disclosure before Palace context or Canvas text is sent off-device.

## Current Co-Writer Path

1. Search local SQLite FTS chunks.
2. Build grounded context from retrieved Palace chunks and active Canvas text.
3. Send context to Ollama.
4. Show answer, citations, confidence, and ward warnings.
5. Require a user action before insertion.

## Provider Seam Needed In M14

Replace the direct Ollama call with:

```text
ProviderSettings + GroundedPrompt -> AiProviderClient -> AiChatResponse
```

## Secrets Boundary

- API keys must never be stored in SQLite.
- API keys must never be exported.
- API keys must never be included in logs, retrieval records, crash messages, or screenshots.
- On macOS, provider keys should be stored in Keychain through a Rust keyring layer.

## Disclosure Requirement

When a user selects a cloud provider, Grimoire must show:

> Cloud model disclosure: Grimoire will send the prompt, relevant Palace excerpts, and active Canvas context needed for this request to the selected provider. Your use of that model is subject to that provider's privacy policy, data processing terms, retention rules, and billing terms. Local-first mode remains available through Ollama.

The user must explicitly acknowledge this before the provider can be used.

## M14 Provider Targets

- Ollama local
- OpenAI
- OpenAI-compatible custom base URL
- Anthropic
- Google AI Studio / Gemini API
```
